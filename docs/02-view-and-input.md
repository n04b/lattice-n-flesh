# 02. Камера, отрисовка, привязки, инструменты

## Камера

Орбитальная камера задаётся параметрами `target` (точка вращения), `yaw`, `pitch`, `dist` и `fov` (вертикальный, 50°).

```
eye   = target + dist · [cos(pitch)·sin(yaw), sin(pitch), cos(pitch)·cos(yaw)]
fwd   = normalize(target − eye)
right = normalize(fwd × [0,1,0])
up    = right × fwd
focal = (H/2) / tan(fov/2)          // H — высота области в CSS-пикселях
```

`pitch` ограничен значением ±1.5707, иначе `right` вырождается.

**Проекция** точки p:
```
d = p − eye;  c = (d·right, d·up, d·fwd)        // c.z — глубина
screen = (W/2 + c.x·focal/c.z,  H/2 − c.y·focal/c.z),   видна при c.z > NEAR = 0.05
```

**Отрезок** отсекается ближней плоскостью в пространстве камеры. Если позади камеры оба конца, отрезок не рисуется. Если один, он заменяется точкой пересечения с плоскостью z = NEAR.

**Луч из пикселя** (sx, sy): начало — `eye`, направление — `normalize(fwd + right·(sx−W/2)/focal − up·(sy−H/2)/focal)`.

Для WebGL используется та же камера: view-матрица строится из строк right / up / −fwd, а projection — стандартная перспективная с f = 1/tan(fov/2) и aspect = W/H. Это даёт ту же формулу экранных координат, что и 2D-проекция.

## Управление камерой

| Действие | Как устроено |
|---|---|
| **Вращение** (ПКМ или Alt+ЛКМ) | `yaw −= dx·0.008`, `pitch += dy·0.008` |
| **Панорама** (СКМ, Shift+ПКМ, Alt+Shift+ЛКМ) | `target += right·(−dx·s) + up·(dy·s)`, где s = dist/focal (мм на пиксель на глубине цели) |
| **Масштаб к курсору** (колесо) | Новая дистанция `nd = clamp(dist·exp(Δ·0.0015), 0.3, 5000)`; для щипка на трекпаде (ctrlKey) коэффициент 0.01. Точка P на луче курсора на глубине `dist` остаётся на месте: `target' = P + (target − P)·(nd/dist)` |
| **Показать всё** | `target` — центр габаритов, `dist = (диагональ/2)/sin(fov/2)·1.05`, с поправкой на узкое окно `·max(1, H/W)` |
| **Готовые виды** | Изо, сверху, спереди, сбоку. Каждый вид заодно переключает рабочую плоскость: XZ, XY или YZ |

## Сетка

Сетка рисуется в рабочей плоскости вокруг проекции цели камеры. Радиус — `max(dist·1.8, 10·шаг)`. Если линий больше 60 на радиус, шаг ×5. Каждая пятая линия ярче. Мировые оси: X — красная, Y — зелёная (только вверх), Z — синяя.

## Рабочая плоскость

Плоскость задаётся нормалью: XZ → ось Y, XY → ось Z, YZ → ось X. Её координата по нормали:
- координата **начальной точки** текущей операции (первая точка ребра или базовая точка перемещения) — так можно рисовать от точки на любой высоте;
- иначе значение «Смещение плоскости».

## Привязки (pickPoint)

Порядок разрешения для курсора (mx, my):

1. **Кандидаты привязки.** Это концы рёбер (штраф 0), середины рёбер (штраф 2 px) и начало координат (штраф 1 px). Берётся кандидат с минимумом «экранное расстояние + штраф» в радиусе 12 px. Кандидаты ближе 70 px (не больше 300) рисуются бледными маркерами.
2. **Фиксация по оси** (Shift, если есть начальная точка P). Для каждой оси X, Y, Z строится её экранная проекция через P; выбирается ось, ближайшая к курсору на экране. Точка на оси вычисляется как ближайшая к лучу курсора:
   ```
   w = P − O; a = D·D; b = D·E; c = E·E; d = D·w; e = E·w
   t = (b·e − c·d) / (a·c − b²)
   ```
   Здесь O, E — начало и направление луча, D — направление оси. Если включена привязка к сетке, t округляется до шага. Если при этом найден кандидат из пункта 1, t = (S − P)·D: ребро дотягивается до уровня этой точки.
3. Если есть кандидат из пункта 1, берётся он.
4. Иначе берётся пересечение луча с рабочей плоскостью (только при t > 0). При привязке к сетке обе координаты в плоскости округляются до шага.

## Выбор рёбер

- **Клик:** ближайшее ребро в пределах 6 px по расстоянию до экранного отрезка (с отсечением). Shift переключает ребро в выделении.
- **Рамка слева направо (окно):** выбираются рёбра, оба конца которых внутри рамки.
- **Рамка справа налево (пересечение):** выбирается ребро, если внутри рамки хотя бы один конец или отрезок пересекает сторону рамки (тест ориентаций).

## Выбор объёмов

- **Клик:** ближайший сегмент каркаса видимой формы в пределах 7 px; выбирается сама форма.
- **Рамка:** выбираются формы, центры которых попадают в рамку.
- Группы выбираются в аутлайнере. Операции применяются к «верхним» выделенным узлам: если выделены и группа, и её потомок, действует только группа.

## Инструменты

| Инструмент | Слой | Поведение |
|---|---|---|
| Выбор (V) | оба | см. выше |
| Ребро (L) | решётка | Клик ставит начало, следующий клик создаёт ребро. С включённой «цепочкой» конец становится новым началом. Цепочка завершается по Esc/Enter/ПКМ или при попадании в первую точку цепочки |
| Перемещение (M) | оба | Базовая точка → точка назначения. Сдвиг d = цель − база |
| Копирование (C) | оба | Как перемещение, но база сохраняется, и можно наставить несколько копий |
| Добавить объём | объёмы | Клик ставит центр новой формы с размерами по умолчанию, затем включается «Выбор» |

Контекстное меню браузера отключено на всей странице. Правая кнопка в окне 3D работает только как вращение и отмена.

Левый клик без смещения больше 4 px считается кликом; иначе это рамка (в инструменте выбора). ПКМ без смещения отменяет текущую операцию.

## Клавиши

Используется `KeyboardEvent.code`, поэтому клавиши работают при любой раскладке.

| Клавиша | Действие |
|---|---|
| V, L, M, C | Инструменты |
| 1 / 2 / 3 | Рабочая плоскость XZ / XY / YZ |
| F | Показать всё |
| Tab | Переключить слой |
| Esc | Отменить операцию, затем снять выделение |
| Enter | Завершить цепочку |
| Del / Backspace | Удалить выделенное |
| ⌘/Ctrl+Z, ⌘/Ctrl+Shift+Z, ⌘/Ctrl+Y | Отмена и повтор |
| ⌘/Ctrl+A | Выделить всё |
| ⌘/Ctrl+S | Сохранить JSON |
| ⌘/Ctrl+G, ⌘/Ctrl+Shift+G | Сгруппировать и разгруппировать объёмы |

## Отрисовка рёбер

- Рёбра делятся на 5 групп по глубине середины (`z/dist`) и рисуются одним путём на группу; альфа от 1 до 0.36. Выделенные — оранжевые и толще.
- Пока тело не построено или скрыто, «мясо» показывается толстыми полупрозрачными отрезками. Ребро режется на 8 частей, толщина линии — 2·r·focal/глубина.
- Каркасы объёмов фиолетовые: ярко в своём слое, бледно в слое решётки.
