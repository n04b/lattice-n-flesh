# 05. Построение тела и экспорт STL

## Неявная поверхность

Тело — множество точек, где F(p) < 0:

```
F(p) = smin_k по всем активным рёбрам e ( dist(p, отрезок e) − r_e(t) )
```

Здесь t — параметр ближайшей точки отрезка (с ограничением [0,1]), а r_e(t) — линейная интерполяция сэмплов ребра (см. 04).

**smin с переменным k.** Рёбра обрабатываются в фиксированном порядке. Аккумулятор хранит текущее значение v и текущий радиус сращивания kv:

```
v = +∞, kv = K_global
для каждого ребра-кандидата:
    dist, t ← ближайшая точка
    если dist − rmax_e ≥ v + max(kv, kmax_e): пропустить     // заведомо не влияет
    r, ke ← интерполяция сэмплов в t
    kk = max(kv, ke);  d = dist − r;  gap = |v − d|
    если gap ≥ kk:  если d < v: v = d, kv = kk
    иначе:          v = min(v, d) − ((kk−gap)/kk)²·kk/4;  kv = kk
```

Сращивание (k) тем сильнее, чем больше kk. При k → 0 получаются отдельные цилиндры со сферическими узлами. При большом k узлы заплывают, а между соседними стержнями растут перепонки, похожие на мыльную плёнку.

Важное свойство: если ребро далеко (gap ≥ kk), его вклад равен нулю точно, а не приближённо. Поэтому значение в точке не зависит от того, было ли в списке далёкое ребро. На этом держится отсутствие щелей при параллельной обработке.

## Сетка сэмплирования

| Величина | Как определяется |
|---|---|
| Шаг h | Финальная сборка: «Разрешение». Черновик: max(Разрешение, габарит/110) |
| Отступ pad | rmax + kmax + 3h |
| Габарит | AABB активных рёбер, расширенный на pad |
| Число узлов по оси | n = ceil(размер/h) + 1 |
| Узел (i, j, z) | bmin + (i, j, z)·h |
| Лимит | nx·ny ≤ 16·10⁶ сэмплов в одном слое |

## Ускорение: грубые ячейки

- Пространство делится на грубые ячейки 8×8 сэмплов в плоскости XY, а по Z — на полосы по 8 слоёв.
- Для каждой полосы Z строится CSR-список сегментов по ячейкам XY. Сегмент попадает в ячейку, если его AABB, расширенный на rmax + kmax + 3h, пересекает ячейку.
- В пустых ячейках значение поля = +∞ (наружу), вычисления пропускаются.
- Порядок сегментов в списках всегда по возрастанию индекса. Для одной и той же точки разные потоки получают одинаковый результат бит в бит.

## Surface nets (послойно по Z)

Сетка обрабатывается слоями. В памяти держатся только три плоскости значений и два слоя индексов вершин ячеек.

**Вершина ячейки.** Ячейка — куб из 8 соседних сэмплов. Если знаки F в углах разные, в ячейке ставится одна вершина: среднее точек пересечения поверхности с 12 рёбрами куба, где точка пересечения на ребре находится при t = v_a/(v_a − v_b). Нормаль вершины — нормированный градиент по 8 углам (разность сумм противоположных граней). Направлена наружу, так как внутри F < 0.

**Грани.** Для каждого ребра решётки сэмплов со сменой знака создаётся четырёхугольник из вершин 4 ячеек, окружающих это ребро. Четырёхугольник делится на 2 треугольника.

| Ребро решётки | Концы | Ячейки (против часовой стрелки, если смотреть с +оси) |
|---|---|---|
| по Z | (i,j,z)→(i,j,z+1) | (i−1,j−1), (i,j−1), (i,j), (i−1,j) — слой z |
| по X | (i,j,z)→(i+1,j,z) | (j−1,z−1), (j,z−1), (j,z), (j−1,z) — в осях (y, z) |
| по Y | (i,j,z)→(i,j+1,z) | (i−1,z−1), (i−1,z), (i,z), (i,z−1) — в осях (x, z) |

Если внутри тела находится начало ребра (F < 0), обход прямой, иначе обратный. Тогда все нормали смотрят наружу.

**Порядок обработки слоя z** (для своего диапазона плоскостей z ∈ [z0, z1)):
1. Вычислить плоскость сэмплов z+1.
2. Вычислить вершины ячеек слоя z (между плоскостями z и z+1).
3. Выдать грани для рёбер по Z из плоскости z, а также для рёбер по X и Y в плоскости z. Для последних нужны слои ячеек z−1 и z.

Перед циклом вычисляются плоскости z0−1, z0 и слой ячеек z0−1. Граница сетки всегда снаружи тела (за счёт pad), поэтому крайние плоскости не обрабатываются: z ∈ [1, nz−1).

## Параллельность

- Плоскости [1, nz−1) делятся на W равных диапазонов, W = min(ядра − 1, плоскости/12, 8).
- Каждый Web Worker получает весь массив сегментов и свой диапазон.
- Соседние воркеры заново вычисляют одну общую плоскость сэмплов и один слой ячеек. Благодаря детерминизму (см. выше) вершины на стыке совпадают бит в бит, поэтому сетка остаётся замкнутой без сшивки.
- Результат каждого воркера — «суп» треугольников: позиции и нормали, по 9 float32 на треугольник. Результаты склеиваются.

## Проверенные свойства

- Каждое ребро сетки принадлежит ровно двум треугольникам (замкнутое многообразие), в том числе на стыке воркеров.
- Ориентированный объём положителен и близок к аналитическому. Для капсулы r = 1, L = 5 при h = 0.1 расхождение около 0,5 %.

## Черновик и финальная сборка

- **Черновик:** запускается автоматически после изменений с крупным шагом.
- **Финальная сборка:** запускается кнопкой «Построить» или перед экспортом STL, с заданным разрешением. Экспорт перестраивает тело, если текущее построено для другой версии, шага или скругления.
- Новая сборка прерывает предыдущую: воркеры уничтожаются, промис прерванной сборки завершается с `null`.

## Просмотр (WebGL)

- Тело хранится в двух буферах (позиции и нормали) и рисуется через `drawArrays(TRIANGLES)` с буфером глубины на среднем холсте.
- Освещение: фонарь от камеры, ключевой свет сверху (0.4, 1, 0.3) и блик (степень 40). Освещение двустороннее: нормаль переворачивается, если смотрит от камеры.
- Пока тело показано, рёбра поверх него рисуются бледнее.

## STL

Треугольники выгружаются как есть. Нормаль грани пересчитывается векторным произведением. Формат описан в [01-model.md](01-model.md).

## Направления развития при переносе

- **Вычисления на GPU.** Плоскость сэмплов — идеальная задача для compute-шейдера.
- **Точнее и меньше треугольников.** Dual contouring (с QEF) даёт острые грани и меньше треугольников; marching cubes — классическую альтернативу.
- **Индексированная сетка.** Вершины ячеек уже уникальны; сейчас они дублируются только при записи в STL и GL.
- **Прореживание** (quadric decimation) после построения.
- **Адаптивная сетка** (октодерево) вместо равномерной: мелкий шаг только у поверхности.
- **Поле вне рёбер.** Вычислять r и k прямо в точке ближайшего сэмпла, а не интерполировать по ребру (см. ограничение в 04).
