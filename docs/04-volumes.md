# 04. Объёмы-модификаторы и поле «мяса»

Объёмы не изменяют рёбра. Они задают **поле**, которое в каждой точке пространства говорит:
- **r(p)** — толщину (радиус) стержня, проходящего через p;
- **k(p)** — радиус сращивания, то есть насколько плавно соседние стержни срастаются в перепонки.

Модификаторы влияют только на рёбра в зоне своего действия (внутри объёма плюс зона затухания). Рёбра, где r = 0, в тело не попадают. При этом выращенное тело может выходить за границу объёма: толщина откладывается от ребра, а объём не обрезает форму.

## Примитивы

Каждый примитив задаётся функцией расстояния со знаком (SDF) в локальных координатах: d < 0 внутри, d > 0 снаружи. Центр примитива в начале координат, ось симметрии — Y.

| Тип | dims (мм) | SDF |
|---|---|---|
| box | sx, sy, sz | q = \|p\| − (s/2); \|max(q,0)\| + min(max(qx,qy,qz), 0) |
| sphere | r | \|p\| − r |
| cyl | r, h | a = \|p.xz\| − r, b = \|p.y\| − h/2; min(max(a,b),0) + \|max((a,b),0)\| |
| cone | r1 (низ), r2 (верх), h | усечённый конус, формула Иниго Квилеса (sdCappedCone) |
| torus | R, r (в плоскости XZ) | \|(\|p.xz\| − R, p.y)\| − r |
| capsule | r, h (длина оси) | \|(p.x, p.y − clamp(p.y, −h/2, h/2), p.z)\| − r |
| half | s (только рамка на экране) | p.y (заполнено всё, что ниже плоскости) |

**Мировые координаты.** SDF_world(p) = SDF(R⁻¹·(p − pos)). Поворот не меняет расстояний, поэтому SDF остаётся точной. Для группы-операции поле только приближённое, этого достаточно для затухания.

**Каркас для экрана.** Каждый тип умеет выдавать набор ломаных `wire(dims, o)`, где o — «раздутие» (для пунктирной границы затухания). Параллелепипед раздувается до размеров s + 2o, сфера до r + o и т. д. У полупространства рамка сдвигается на o вдоль нормали.

## Группы

- **Папка** (`folder`) только группирует: каждый потомок действует как самостоятельный модификатор.
- **Объединение, вычитание, пересечение** объединяют потомков в одну форму. Потомки-формы тогда задают только геометрию: их `mod` игнорируется, а действует `mod` группы.
  ```
  union:     v = smin(v, b, k)
  intersect: v = −smin(−v, −b, k)
  subtract:  v = −smin(−v, b, k)          // первый потомок минус остальные, слева направо
  smin(a,b,k) = min(a,b) − h²·k/4,  h = max(k − |a−b|, 0)/k     (k = 0 → обычный min)
  ```
- Вложенная папка внутри группы-операции считается объединением.
- Скрытые узлы (`hidden`) пропускаются целиком, вместе с потомками.

**Корень модификатора** — узел, у которого все предки папки и который сам не папка. Список модификаторов собирается обходом дерева в глубину в порядке списка. Действуют только включённые корни (`mod.on`), у которых thick > 0 или режим не «максимум».

## Поле в точке

Для каждого модификатора m по порядку:
```
d = SDF_m(p)
w = 1,                       если d ≤ 0
    0,                       если d ≥ fall
    curve(d / fall),         иначе
v = thick · w
r = max(r, v)  |  r + v  |  r − v          // mode: max | add | sub
k = max(k, blend · w)
```
В конце r = max(r, 0). Начальные значения r = 0, k = 0.

Кривые спада, t ∈ [0, 1):

| Кривая | Формула |
|---|---|
| Плавная | 1 − t²(3 − 2t) |
| Линейная | 1 − t |
| Выпуклая | 1 − t² |
| Вогнутая | (1 − t)² |
| Ступенька | 0 (резкая граница) |

## Сэмплирование вдоль рёбер

Поле вычисляется не в каждой точке пространства, а в N+1 равномерных точках каждого ребра. Получаются пары (r_i, k_i). Внутри ребра значения интерполируются линейно по параметру t ближайшей точки отрезка.

- **Для экрана:** N = 8.
- **Для тела:** N = clamp(ceil(длина/(2·шаг)), 8, 128).
- Ребро считается активным, если max r_i > 0.
- Глобальное «Скругление узлов» — нижняя граница для всех k_i.

Сэмплирование по ребру — главное упрощение. Объём меньше расстояния между сэмплами может «проскочить» мимо ребра. При переносе можно вычислять поле адаптивно или прямо в мешере.

## Пересчёт

Любое изменение рёбер, объёмов или параметров тела увеличивает счётчик версии `geomVer`. Через 30 мс пересчитывается экранное поле (сэмплы по 8 на ребро). Ещё через 300 мс запускается черновая сборка тела, если она включена и тело для этой версии ещё не строится и не построено.
