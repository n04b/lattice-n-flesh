# Рёберный 3D-редактор — документация

Редактор решётчатых структур. Пользователь строит **решётку из рёбер** (слой 1), затем расставляет **объёмы-модификаторы** (слой 2). Объёмы задают, сколько «мяса» нарастить на рёбра. Итоговое твёрдое тело экспортируется в STL для 3D-печати.

Документация описывает все механики независимо от языка реализации, чтобы проект можно было перенести на более быстрый стек (C++/Rust/C#, GPU-вычисления).

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны: скрипты подключаются обычными тегами `<script>`, без ES-модулей, поэтому работают и по `file://`. Для проверки в среде, где `file://` недоступен, есть `.claude/launch.json` (запускает `python3 -m http.server 8765`).

## Структура кода

Все файлы `js/*.js` разделяют одну глобальную область видимости и подключаются в указанном порядке.

| Файл | Ответственность |
|---|---|
| `index.html` | Разметка: панель инструментов, три холста, боковая панель, строка состояния |
| `css/style.css` | Стили; видимость элементов по слою через `body[data-layer]` и атрибут `data-only` |
| `js/math.js` | Векторы `[x,y,z]`, ключи округления для дедупликации, форматирование чисел |
| `js/state.js` | Глобальное состояние, камера и проекция, история (undo/redo), добавление и удаление рёбер |
| `js/snap.js` | Рабочая плоскость, привязки, фиксация по оси, выбор рёбер (клик и рамка) |
| `js/render.js` | 2D-отрисовка: сетка, рёбра, предпросмотр «мяса», каркасы объёмов, маркеры, гизмо осей |
| `js/tools.js` | Инструменты (выбор, ребро, перемещение, копирование, добавление объёма), виды камеры |
| `js/input.js` | Мышь, колесо, клавиатура |
| `js/files.js` | Сохранение и открытие JSON, импорт и экспорт OBJ |
| `js/panels.js` | Привязка кнопок панели инструментов |
| `js/polyhedra.js` | Библиотека многогранников |
| `js/generator.js` | Генератор структур и его интерфейс |
| `js/volumes.js` | Примитивы, дерево объёмов, SDF, поле толщины и сращивания |
| `js/mesher.js` | Код Web Worker: поле → треугольники (surface nets) |
| `js/body.js` | Запуск сборки в воркерах, WebGL-просмотр тела, запись STL |
| `js/volume-ui.js` | Слой объёмов: переключение слоя, аутлайнер, инспектор, группы |
| `js/main.js` | Инициализация |

## Три слоя отрисовки

В области просмотра наложены три холста одного размера:

1. `#bg` (2D) — сетка рабочей плоскости и мировые оси;
2. `#gl` (WebGL) — твёрдое тело с освещением и буфером глубины;
3. `#cv` (2D, принимает ввод) — рёбра, каркасы объёмов, маркеры, подсказки.

Все три слоя используют одну и ту же камеру и одну формулу проекции, поэтому совпадают пиксель в пиксель.

## Рекомендации по переносу

- Самая тяжёлая часть — вычисление поля и построение сетки (05). Её стоит переносить первой: SIMD, многопоточность или вычислительные шейдеры.
- Редактор хранит рёбра как независимые пары точек, без общих вершин. Связность определяется совпадением координат с округлением до 1e-4 мм. При переносе можно ввести таблицу вершин, но правила дедупликации нужно сохранить.
- Все расчёты детерминированы. Совпадение результатов на границах параллельных участков обеспечивается одинаковым порядком операций (см. 05).
