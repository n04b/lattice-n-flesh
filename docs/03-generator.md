# 03. Генератор многогранников и структур

Генератор строит список рёбер `[[a,b], ...]`. Пока параметры меняются, этот список показывается как предпросмотр. По кнопке «Создать» рёбра добавляются через `addEdges` (с дедупликацией относительно сцены). Лимит — 200 000 рёбер: его проверяет предварительная оценка «число копий × рёбер в базе».

## Многогранники (длина ребра = 1)

### Вершины из шаблонов

Вершины задаются базовыми тройками и правилом перестановок:
- `cyc` — 3 циклические перестановки;
- `perms` — все 6 перестановок;
- без перестановок.

Затем перебираются все знаки ненулевых координат, после чего вершины дедуплицируются по ключу.

**Рёбра для правильных и архимедовых тел** — пары вершин на минимальном попарном расстоянии m (допуск 1e-3·m). Затем всё масштабируется на 1/m.

| Тело | Шаблон (φ — золотое сечение) | Вершин / рёбер |
|---|---|---|
| Тетраэдр | (1,1,1), знаки с чётным числом минусов | 4 / 6 |
| Куб | (1,1,1) | 8 / 12 |
| Октаэдр | cyc (1,0,0) | 6 / 12 |
| Додекаэдр | (1,1,1) и cyc (0, 1/φ, φ) | 20 / 30 |
| Икосаэдр | cyc (0, 1, φ) | 12 / 30 |
| Кубооктаэдр | cyc (1,1,0) | 12 / 24 |
| Усечённый тетраэдр | perms (3,1,1), чётное число минусов | 12 / 18 |
| Усечённый октаэдр | perms (0,1,2) | 24 / 36 |
| Усечённый куб | perms (√2−1, 1, 1) | 24 / 36 |
| Ромбокубооктаэдр | perms (1, 1, 1+√2) | 24 / 48 |
| Икосододекаэдр | cyc (0,0,φ) и cyc (½, φ/2, φ²/2) | 30 / 60 |
| Усечённый икосаэдр | cyc (0,1,3φ), (1, 2+φ, 2φ), (φ, 2, 2φ+1) | 60 / 90 |
| Звёздчатый октаэдр | вершины куба, рёбра — пары на расстоянии 2√2, масштаб 1/(2√2) | 8 / 12 |

### Параметрические тела

Для правильного N-угольника с ребром 1 радиус описанной окружности R = 0.5/sin(π/N). Кольцо из N точек: угол 2πi/N, плоскость XZ.

- **Призма:** кольца на y = ±0.5, соединены вертикалями.
- **Антипризма:** верхнее кольцо повёрнуто на π/N. Высота h = √(1 − c²), где c = 2R·sin(π/2N). Нижняя вершина i соединена с верхними i и i−1.
- **Пирамида:** вершина над центром на высоте h = √(1−R²), если R < 1, иначе 0.8R. **Бипирамида** — то же с двумя вершинами (±h).
- **Геодезическая сфера частоты f:**
  1. Икосаэдр поворачивается вокруг X на −atan2(φ,1), чтобы вершина смотрела вверх.
  2. Грани — тройки взаимно смежных вершин (i<j<k).
  3. Каждая грань ABC делится на точки A + (B−A)·u/f + (C−A)·v/f при u+v ≤ f. Точки проецируются на единичную сферу и дедуплицируются по ключу.
  4. Рёбра — три соседа в треугольной решётке.
  5. **Купол** оставляет рёбра, у которых обе вершины имеют y ≥ −1e-6; вершины без рёбер удаляются.
  
  Размер здесь задаёт радиус, а не длину ребра.
- **Тессеракт:** 16 вершин (±1)⁴ и 32 ребра (вершины, отличающиеся одной координатой). Проекция в 3D — перспективная: (x,y,z)/(3−w).

### Подготовка базового тела

Базовое тело центрируется по центру габаритного параллелепипеда, умножается на «Размер» и поворачивается на заданные углы X, Y, Z (порядок — см. 01).

## Структуры

Вспомогательная функция `place(смещение, масштаб, поворот)` добавляет копию базы, применяя к вершинам p преобразование `поворот(p·масштаб) + смещение`. Габарит базы ext — размер её AABB.

| Структура | Расстановка копий |
|---|---|
| Одиночный | одна копия в 0 |
| Решётка | nx×ny×nz копий; смещение `(i − (n−1)/2)·ext·шаг` по каждой оси; при шаге 1 копии касаются |
| Кольцо | N копий на окружности радиуса R, угол a = 2πi/N; «к центру» — поворот вокруг Y на −a |
| Спираль | t = i/(N−1), угол t·витки·2π, высота t·H, масштаб линейно от 1 до «Масштаба в конце», поворот вдоль спирали |
| Башня | ярусы друг на друге: масштаб s_i = s_end^t; центр яруса y_i = y_{i−1} + ext_y·(s_{i−1}+s_i)/2; поворот вокруг Y на i·закрутка |
| Фрактал | рекурсия глубины L: копия масштаба s в центре c заменяется копиями масштаба s·f в точках c + v·s·(1−f) для каждой вершины v базы. Вершины подкопий совпадают с вершинами родителя; для тетраэдра при f = ½ получается пирамида Серпинского |
| Облако | N копий в случайных точках шара радиуса R (метод отбора). Масштаб 0.5…1.3, случайный поворот. ГСЧ — xorshift32 с затравкой |
| Октет-ферма | узлы ГЦК-решётки (углы кубов и центры граней) в nx×ny×nz ячейках с ребром ячейки a·√2; каждый узел соединён с 12 соседями на смещениях cyc(±½, ±½, 0); длина стержня = a |

## Финальная обработка

1. Перенос в «Центр X/Y/Z».
2. Если включено «Основание на уровне Y», вся структура сдвигается так, чтобы минимум по Y совпал с Y центра.
3. Дедупликация рёбер по ключу и удаление вырожденных рёбер.
